Part 1 – Answers

    1. What does it mean to run an AI model locally?
    
        Running an AI model locally means that the model is executed directly on your own computer instead of sending requests to an external server or API. All the processing happens on your machine, so your data stays local.

    2. What are the advantages of running models locally instead of using an API?
    
        One big advantage is privacy, since your data is not sent to external services. It also gives you full control over the model and how it is used. You don’t need API keys or worry about usage limits or costs. Another benefit is that it can work offline once everything is set up.

    3. What are some limitations of running models locally?
        
        The biggest limitation is hardware. Large models require a lot of RAM and GPU power, which many computers don’t have. It can also be slower compared to cloud-based solutions, and setting everything up can be more complex.

    4. What is Ollama (or similar tools) used for?
        
        Ollama is a tool that makes it easy to run large language models locally on your computer. It handles downloading, managing, and running models so developers can use them without needing deep knowledge of infrastructure.

    5. How is this similar to what we did with Hugging Face?
        
        It is similar because both involve loading a model and using it to make predictions or generate text. The main difference is that with Hugging Face we often use hosted models or APIs, while here everything runs locally on our machine.

    
    Part 2 – Reflection

        This approach is similar to CountVectorizer + ML model because both run locally and process data directly on your machine. In both cases, you have full control over the data and the model.

        It is also similar to Hugging Face pipelines because we still use pre-trained models to perform tasks like text generation or classification. The workflow (input → model → output) is basically the same.

        The main difference between classical ML models and modern AI models (LLMs) is their complexity and capability. Classical models are usually smaller, faster, and designed for specific tasks like classification. LLMs, on the other hand, are much larger and more flexible—they can understand context, generate text, and handle many different tasks with one model.
